# 新增卡片流程

本文檔說明如何在 NTN Energy Management Platform 中新增新的卡片類型，包括顯示組件和編輯流程的完整步驟。

## 概述

系統支援多種類型的卡片，每種卡片都有對應的顯示組件和編輯組件。新增卡片需要：

1. 定義卡片類型枚舉(Enum)
2. 創建顯示組件和樣式
3. 創建編輯組件和樣式
4. 創建卡片定義服務
5. 更新主編輯器路由

## 步驟詳解

### 1. 定義卡片類型

在 `Models/cardInfo.cs` 中新增卡片類型枚舉值：

```csharp
public enum CardType
{
    Info,
    Chart,   
    Status,  // RunningDiagram
    // 新增你的卡片類型，例如：
    // NewCardType
}
```

### 2. 創建顯示組件

在 `Components/Shared/` 下創建新的資料夾，例如 `NewCard/`，並建立顯示組件：

**NewCard.razor**
```razor
@namespace demoVer.Shared
@inherits LayoutComponentBase

@using demoVer.Models
@using Microsoft.AspNetCore.Components

<div class="new-card">
    <h3>@currentCardInfo.cardName</h3>
    <!-- 你要顯示的內容 -->
</div>

@code {
    [Parameter] public CardInfo currentCardInfo { get; set; } = default!;
}
```

**NewCard.razor.css**
```css
.new-card {
    /* 你的樣式 */
}
```

### 3. 創建編輯組件

在相同資料夾下創建編輯組件：

**NewCardEdit.razor**
```razor
@namespace demoVer.Shared
@inherits LayoutComponentBase

@using demoVer.Models
@using Microsoft.AspNetCore.Components

<div class="new-card-editor">
    <h3>編輯 : @currentCardInfo.cardName</h3>
    <!-- 你的編輯UI -->
    
    <MudButton OnClick="ConfirmChanges"
               Variant="Variant.Filled"
               Color="Color.Success">
        確定
    </MudButton>
</div>

@code {
    [Parameter] public CardInfo currentCardInfo { get; set; } = default!;
    [Parameter] public EventCallback<CardInfo> OnCardInfoUpdated { get; set; }

    private void ConfirmChanges()
    {
        // 更新卡片資料
        OnCardInfoUpdated.InvokeAsync(currentCardInfo);
    }
}
```

**NewCardEdit.razor.css**
```css
.new-card-editor {
    /* 編輯器樣式 */
}
```

### 4. 創建服務，用於定義卡片。

在 `Services/` 下創建新的定義類別：

**NewCardDefinition.cs**
```csharp
using System.Collections.Generic;
using demoVer.Interfaces;
using demoVer.Models;
using demoVer.Shared;

namespace demoVer.Services;

public sealed class NewCardDefinition : ICardDefinition
{
    public CardType CardType => CardType.NewCardType;
    public Type DisplayComponent => typeof(NewCard);
    public Type EditorComponent => typeof(NewCardEdit);
    public string DisplayName => "新卡片";
    public string ThumbnailPath => "images/cardSelection-new.png";
    public string DefaultWidthClass => "w50";

    public CardInfo CreateDefaultCard() => new()
    {
        card_Type = CardType.NewCardType,
        widthClass = DefaultWidthClass,
        cardName = "New Card",
        // 初始化你的卡片特定資料
    };
}
```

### 5. 在 Program.cs 中註冊服務

在 `Program.cs` 的服務註冊區段新增：

```csharp
builder.Services.AddSingleton<ICardDefinition, NewCardDefinition>();
```

確保新增在其他卡片定義之後，例如：

```csharp
builder.Services.AddSingleton<ICardDefinition, InfoCardDefinition>();
builder.Services.AddSingleton<ICardDefinition, ChartCardDefinition>();
builder.Services.AddSingleton<ICardDefinition, RunningDiagramCardDefinition>();
builder.Services.AddSingleton<ICardDefinition, NewCardDefinition>(); // 新增這行
```

### 6. 更新主編輯器

在 `Components/Shared/EditCard.razor` 中新增 case：

```razor
@switch (currentCardInfo.card_Type)
{
    // ... 現有 cases ...
    case CardType.NewCardType:
        <NewCardEdit currentCardInfo="currentCardInfo"
                     OnCardInfoUpdated="OnCardInfoUpdated" />
        break;
}
```

## 範例：RunningDiagram 卡片

參考 `Components/Shared/RunningDiagram/` 下的實現：

- **顯示組件**: `RunningDiagramCard.razor`
- **編輯組件**: `RunningDiagramCardEdit.razor`
- **定義服務**: `Services/RunningDiagramCardDefinition.cs`

這個範例展示了完整的編輯流程，包括圖標選擇、文字輸入和狀態管理。
